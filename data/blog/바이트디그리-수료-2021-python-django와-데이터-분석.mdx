# 첫 회사 재직 중 수료한 온라인 과정 두 개 (2021-11)

2021년 11월, [산업 AI 판독 시스템](/blog/2021년도~2022년도의-산업-ai-솔루션) 프런트엔드로 일하던 시기에 패스트캠퍼스 Byte Degree 과정 두 개를 마쳤습니다. 당시에는 따로 글을 남기지 않았고, 2026년 9월에 외장 하드에서 수료증을 찾아 정리한 것이라 **과정 중에 무엇을 느꼈는지는 남아 있지 않습니다.** 수료증에 적힌 사실만 적습니다.

## 한눈에 보기

| 과정 | 발급일 | 수료증에 적힌 내용 |
|---|---|---|
| Python & Django Essential – Associate | 2021-11-03 | HTML·CSS·JavaScript, BeautifulSoup 크롤링, Django 프레임워크. 이수 과제: **Django를 사용한 장고스타그램 웹 플랫폼 만들기** |
| Data Science with Python – Associate | 2021-11-22 | 데이터 분석 기획, Python 웹 크롤링, Numpy·Pandas. 통과 과제: **구글 플레이스토어 데이터를 활용한 데이터 분석** |

## 지금 보면

프런트엔드로 커리어를 시작한 첫 해에 Django를 처음 만진 기록입니다. 이때는 튜토리얼 수준이었고, 실제로 Django API와 쿼리를 맡게 된 것은 4년 뒤 [SDMS](/blog/2025년도~현재의-sdms)에서였어요. 그 사이에 [PyNews](/projects) 같은 사이드 프로젝트가 있었습니다.

**정확하지 않은 것 하나.** [Timeline](/timeline)에는 같은 시기에 국비지원 교육 두 건(빅데이터 분석 첫걸음, python & django로 시작하는 웹 프로그래밍)이 2021-11-10 시작으로 적혀 있습니다. 이 수료증들과 같은 과정인지, 별개인지 확인할 자료가 남아 있지 않아 둘 다 그대로 둡니다.

# 99클럽 코테 스터디 29일차 TIL + 오늘의 학습 키워드: 동적계획법

> 이 글은 [네이버 블로그](https://blog.naver.com/ggamjige8888/223787171750)에 2025년 3월 7일에 올렸던 것을 그대로 옮겨온 것입니다.

```js
const fs = require('fs');
const [n, ...arr] = fs.readFileSync("/dev/stdin").toString().trim().split("\n").map(v => +v);

const MAX = Math.max(...arr);

let dp = [];
dp[0] = 1;
dp[1] = 1;
dp[2] = 1;

for (let i = 3; i <= MAX + 1; i++) {
  dp[i] = dp[i - 3] + dp[i - 2];
}

arr.forEach(v => {
  console.log(dp[v - 1]);
})
```

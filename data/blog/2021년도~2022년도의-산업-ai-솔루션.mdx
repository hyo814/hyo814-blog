## 핵심 역량

### 1. 판독 화면 (관세청 불법 복제품 판독 시스템)

![판독 시스템](/static/images/ai-vision/image3.webp)
*출처: 이데일리 뉴스 참조*

정품과 복제품의 차이는 로고 마감이나 봉제선 같은 미세한 부분에서 납니다. 그런데 화면에서 그 부분을 확인할 방법이 부족했습니다. 그래서 **확대/축소와 이미지 크롭**을 넣어 판독관이 판정 근거를 화면에서 직접 확인하게 했고, React 비동기 처리로 **이미지 최소 5장을 나란히 비교**하는 화면을 만들었습니다.

모바일 웹뷰에서는 **아코디언 UI**로 상위 5개 결과를 요약해 보여 주고 필요할 때 펼치게 했습니다. 당시 보고서에는 탐색 시간 40% 단축으로 남아 있지만 측정 방법은 보존되지 않았습니다.

### 2. 실시간 판독 (공항 보안 검색 판독 시스템)

![판독 시스템](/static/images/ai-vision/image.gif)
![판독 시스템](/static/images/ai-vision/image2.webp)
*출처: SECON 사진 촬영 및 아시아투데이 뉴스 일부 캡쳐*

보안 검색은 물건이 지나가는 순간에 결과가 떠야 의미가 있어서, **WebSocket 양방향 통신**으로 비디오 판독 결과를 실시간으로 받았습니다. 두 각도의 영상을 나란히 봐야 하는 검색 방식에 맞춰 단화면·양화면 모드와 줌을 만들었고, 두 창의 설정은 localStorage와 소켓 메시지로 맞췄습니다. 시스템은 공항에 장비와 함께 납품됐습니다.

- [단화면·양화면 두 창의 설정을 맞춘 방법](/blog/설정을-localstorage에-두고-소켓-메시지-16갈래로-창끼리-맞췄다)

### 3. SPA 전환 (직접 제안)

옛 화면은 판독·검색·통계를 한 HTML 안에 두고 `display:none`으로 바꿔 가며 보여 주는 바닐라 JavaScript 구조였습니다. 같은 판독 화면이 프로젝트마다 조금씩 다르게 복사되는 것을 보고 React SPA 전환을 제안했고, 2021-04, 2021-10, 2022-03 세 차례에 걸쳐 옮겼습니다. 화면을 컴포넌트로 조립할 수 있게 되면서 회사별 커스텀 요청에 대응하는 속도가 빨라졌습니다.

- [옛 화면과 React SPA가 한 저장소에 같이 있던 이유](/blog/바닐라-jinja-화면과-react-spa가-한-저장소에-같이-있었다)

### 4. 납품처별 설정

납품처마다 보고 싶은 것과 기준이 달랐습니다. 요구가 올 때마다 분기 코드를 넣는 대신, 판독 상자를 그리는 **클래스별 색·임계값·표시 여부** 세 가지를 설정으로 빼서 받았습니다.

- [판독 상자를 그리는 서버 설정 세 가지](/blog/메인-화면의-판독-박스는-서버-설정-셋이-그린다)

### 5. 통계 시각화

금지 품목의 패턴을 볼 수 있도록 직선·도넛·원형 그래프를 만들고, 통계 조건을 사용자가 직접 정하게 했습니다. 세계 보안 엑스포(SECON) 2021·2022 전시 부스에서는 이 화면들을 직접 시연했습니다.

# [ZBF] 6월 7일차 코딩 테스트 : 팰린드롬(palindrome) / 회문

> 이 글은 [네이버 블로그](https://blog.naver.com/ggamjige8888/223471618587)에 2024년 6월 7일에 올렸던 것을 그대로 옮겨온 것입니다.

**팰린드롬(palindrome)은 앞에서부터 읽으나 뒤에서부터 읽으나 같은 문자열을 말합니다. 예를 들어, "level", "radar", "racecar" 등이 있습니다. 팰린드롬을 판별하는 알고리즘은 문자열 처리와 관련된 다양한 문제를 해결하는 데 유용합니다.**

**양 끝에서 중앙으로 이동하면서 문자가 같은지 확인하는 방식입니다.**

**팰린드롬 판별 문제**

```js
function isPalindrome(str) {
// 문자열의 양 끝 인덱스를 초기화
let left = 0;
let right = str.length - 1;

// 양 끝에서 중앙으로 이동하며 문자를 비교
while (left < right) {
if (str[left] !== str[right]) {
return false; // 문자가 다르면 팰린드롬이 아님
}
left++;
right--;
}

return true; // 모든 문자가 같다면 팰린드롬
}
```

**최적화된 팰린드롬 판별 문제**

```js
function isPalindromeOptimized(str) {
// 문자열을 소문자로 변환하고 공백을 제거
str = str.toLowerCase().replace(/\s+/g, '');

let left = 0;
let right = str.length - 1;

while (left < right) {
if (str[left] !== str[right]) {
return false;
}
left++;
right--;
}

return true;
}
```

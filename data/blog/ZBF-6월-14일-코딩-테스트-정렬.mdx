# [ZBF] 6월 14일 코딩 테스트 : 정렬

> 이 글은 [네이버 블로그](https://blog.naver.com/ggamjige8888/223480909979)에 2024년 6월 16일에 올렸던 것을 그대로 옮겨온 것입니다.

**1. 버블 정렬 (Bubble Sort)**

버블 정렬은 인접한 두 원소를 비교하여 순서가 잘못된 경우 서로 교환하는 방식입니다. 가장 큰 원소가 맨 끝으로 "버블"처럼 올라가는 모습을 띱니다.

```js
// 버블 정렬 예제
function bubbleSort(arr) {
    let len = arr.length;
    for (let i = 0; i < len; i++) {
        for (let j = 0; j < len - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                // Swap
                let temp = arr[j];
                arr[j] = arr[j + 1];
                arr[j + 1] = temp;
            }
        }
    }
    return arr;
}
```

**2. 선택 정렬 (Selection Sort)**

선택 정렬은 매번 최솟값을 찾아서 앞쪽으로 보내는 방식입니다. 리스트의 처음부터 끝까지 순회하면서 가장 작은 값을 선택하여 맨 앞의 값과 교환합니다.

```js
// 선택 정렬 예제
function selectionSort(arr) {
    let len = arr.length;
    for (let i = 0; i < len; i++) {
        let minIndex = i;
        for (let j = i + 1; j < len; j++) {
            if (arr[j] < arr[minIndex]) {
                minIndex = j;
            }
        }
        if (minIndex != i) {
            // Swap
            let temp = arr[i];
            arr[i] = arr[minIndex];
            arr[minIndex] = temp;
        }
    }
    return arr;
}
```

**3. 삽입 정렬 (Insertion Sort)**

삽입 정렬은 이미 정렬된 부분과 아직 정렬되지 않은 부분으로 나눠서, 정렬되지 않은 부분의 첫 번째 원소를 정렬된 부분의 올바른 위치에 삽입하는 방식입니다.

```js
// 삽입 정렬 예제
function insertionSort(arr) {
    let len = arr.length;
    for (let i = 1; i < len; i++) {
        let key = arr[i];
        let j = i - 1;
        while (j >= 0 && arr[j] > key) {
            arr[j + 1] = arr[j];
            j = j - 1;
        }
        arr[j + 1] = key;
    }
    return arr;
}
```

**4. 병합 정렬 (Merge Sort)**

병합 정렬은 분할 정복 알고리즘의 일종으로, 배열을 반씩 나누어 정렬한 후 병합하는 방식입니다. 안정적인 정렬 방법 중 하나입니다.

```js
// 병합 정렬 예제
function mergeSort(arr) {
    if (arr.length <= 1) {
        return arr;
    }
    
    const middle = Math.floor(arr.length / 2);
    const left = arr.slice(0, middle);
    const right = arr.slice(middle);
    
    return merge(mergeSort(left), mergeSort(right));
}

function merge(left, right) {
    let result = [];
    while (left.length && right.length) {
        if (left[0] < right[0]) {
            result.push(left.shift());
        } else {
            result.push(right.shift());
        }
    }
    return result.concat(left, right);
}
```

**5. 퀵 정렬 (Quick Sort)**

퀵 정렬은 배열의 원소 하나를 피벗으로 선택하고, 피벗보다 작은 원소는 왼쪽, 큰 원소는 오른쪽으로 분할한 뒤 각각 정렬하는 방식입니다.

```js
// 퀵 정렬 예제
function quickSort(arr) {
    if (arr.length <= 1) {
        return arr;
    }
    
    const pivot = arr[arr.length - 1];
    const left = [];
    const right = [];
    
    for (let i = 0; i < arr.length - 1; i++) {
        if (arr[i] < pivot) {
            left.push(arr[i]);
        } else {
            right.push(arr[i]);
        }
    }
    
    return [...quickSort(left), pivot, ...quickSort(right)];
}
```

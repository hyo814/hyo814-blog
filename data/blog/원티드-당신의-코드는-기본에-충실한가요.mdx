# [원티드] 당신의 코드는 기본에 충실한가요?

> 이 글은 [네이버 블로그](https://blog.naver.com/ggamjige8888/223551845329)에 2024년 8월 18일에 올렸던 것을 그대로 옮겨온 것입니다.

- **반응형 웹사이트 개발의 기초**
- **반응형 웹, 디자인 개념, 도구의 사용**
- 반응형 웹사이트의 범위
- 픽셀과 벡터의 차이
- 해상도외 밀도
- 사이즈의 종류와 특징
- 개발자 도구 활용법
- 디자인툴 기본 사용법(포토샵, 피그마, XD, 스케치)

- **모바일 웹사이트를 개발해봅시다.**
- **뷰포트, UX, 스크린사이즈, 박스모델**
- viewport의 의미
- 웹표준이란?
- 박스모델
- 다양한 레이아웃 제작 기법
- 사용성을 고려한 코드 작성

- **태블릿 웹사이트를 개발해봅시다.**
- **Media Query, CSS 계산**
- 미디어쿼리의 사용법
- 다양한 미디어쿼리의 활용
- JavaScript를 이용한 화면 사이즈 분기
- 미디어쿼리는 단순히 사이즈만 나누는 것이 아니다.

- **데스크탑 웹사이트를 개발해봅시다.**
- **크로스웹, 웹사이트 운영, 사이트 최적화**
- 다양한 브라우져 호환성
- 운영을 고려한 코드 수정
- 사이트 최적화 기법
- 디테일에 집착해라.

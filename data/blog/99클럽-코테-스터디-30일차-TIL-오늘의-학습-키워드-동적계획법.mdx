# 99클럽 코테 스터디 30일차 TIL + 오늘의 학습 키워드: 동적계획법

> 이 글은 [네이버 블로그](https://blog.naver.com/ggamjige8888/223787169022)에 2025년 3월 7일에 올렸던 것을 그대로 옮겨온 것입니다.

```js
function maxBoxes(n, sizes) {
    // dp 배열 초기화: 각 상자를 포함할 때의 최대 상자 개수
    const dp = new Array(n).fill(1);

    // 모든 상자에 대해 반복
    for (let i = 1; i < n; i++) {
        for (let j = 0; j < i; j++) {
            // 앞의 상자 크기가 현재 상자 크기보다 작으면 dp 갱신
            if (sizes[j] < sizes[i]) {
                dp[i] = Math.max(dp[i], dp[j] + 1);
            }
        }
    }

    // dp 배열에서 최대값 반환
    return Math.max(...dp);
}

// 예제 입력
const n = 8;
const sizes = [1, 6, 2, 5, 7, 3, 5, 6];

// 결과 출력
console.log(maxBoxes(n, sizes)); // 출력: 5
```

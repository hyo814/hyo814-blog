# waitMe

공식 문서 : https://vadimsva.github.io/waitMe/

`waitMe`는 jQuery 기반의 **로딩 애니메이션 플러그인**

어떤 DOM 요소든지 로딩 중임을 시각적으로 표시

예를 들어, 버튼 클릭 시 로딩 스피너를 표시하거나 전체 화면을 블로킹할 때 유용.

---

### 기본 사용법

```html
<!-- jQuery & waitMe 라이브러리 불러오기 -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/waitme@1.19.0/waitMe.min.css">
<script src="https://code.jquery.com/jquery-3.6.0.min.js"></script>
<script src="https://cdn.jsdelivr.net/npm/waitme@1.19.0/waitMe.min.js"></script>

```

```jsx
// waitMe 실행
$('#target-element').waitMe({
  effect: 'bounce',
  text: '로딩 중입니다...',
  bg: 'rgba(255,255,255,0.7)',
  color: '#000',
  maxSize: '',
  waitTime: -1,
  textPos: 'vertical',
  fontSize: '',
  source: '',
  onClose: function() {}
});

```

```jsx
// waitMe 종료
$('#target-element').waitMe('hide');

```

### 전체 화면에 로딩 표시

```jsx
$('body').waitMe({
  effect: 'bounce',
  text: '페이지 로딩 중...',
  bg: 'rgba(0,0,0,0.4)',
  color: '#fff',
});

```

```jsx
// 일정 시간 후 자동 종료
setTimeout(() => {
  $('body').waitMe('hide');
}, 3000);

```

---

### 주요 옵션 설명

| 옵션 | 설명 |
| --- | --- |
| `effect` | 로딩 애니메이션 종류 |
| `text` | 표시할 텍스트 |
| `bg` | 배경 색상 (투명도 포함) |
| `color` | 로딩 아이콘 색상 |
| `maxSize` | 아이콘 최대 크기 |
| `waitTime` | 자동 종료 시간 (ms). -1이면 무제한 |
| `textPos` | 텍스트 위치: vertical/horizontal |
| `fontSize` | 텍스트 크기 |
| `onClose` | hide될 때 호출할 콜백 |

### 예제 - 버튼 클릭 시 로딩

```html
<button id="loadBtn">불러오기</button>
<div id="contentBox"></div>

<script>
  $('#loadBtn').on('click', function() {
    $('#contentBox').waitMe({
      effect: 'stretch',
      text: '데이터 불러오는 중...',
      bg: 'rgba(255,255,255,0.7)',
      color: '#000'
    });

    // 예시: 2초 후 로딩 종료
    setTimeout(() => {
      $('#contentBox').waitMe('hide');
    }, 2000);
  });
</script>

```

## 실무에서 자주 놓치는 포인트 정리

### 1. **`waitMe`는 jQuery 기반**

- **jQuery가 필수**

프로젝트가 React, Vue, Next.js 기반이면 그냥 쓸 수 없음.
👉 `$(...)` 구문 자체가 없기 때문.

- 해결 방법:
  - jQuery를 별도로 로드하거나,
  - `waitMe` 대신 Vanilla JS 기반의 로딩 라이브러리를 사용하는 것이 더 선호
(예: [Spin.js](https://spin.js.org/), CSS 로딩 컴포넌트 등).

---

### 2. **중복 호출 시 로딩이 꼬임**

```
// 잘못된 사용 - 연속 호출 시 기존 waitMe 안 꺼짐
$('#target').waitMe(...);
$('#target').waitMe(...);

```

- 해결 방법:

  ```
  $('#target').waitMe('hide'); // 먼저 닫고
  $('#target').waitMe({...}); // 다시 실행

    ```


---

### 3. **hide는 명시적으로 호출해야 함**

- `waitTime` 옵션을 쓰지 않으면 자동 종료되지 않음.
- 무조건 `.waitMe('hide')`를 호출해서 로딩을 꺼줘야 함.

---

### 4. **`onClose` 콜백은 `hide`할 때만 실행됨**

```
$('#target').waitMe({
  onClose: function() {
    console.log('로딩 종료됨');
  }
});

```

> 위 콜백은 로딩 시작할 때가 아니라, hide가 호출된 후에만 실행됨
>

---

### 5. **전체 화면 로딩 시 `body` 외에도 `html` 같이 스타일 지정 필요할 수 있음**

- waitMe는 `position: relative`가 설정된 부모 요소 위에 붙기 때문에,
body에 적용할 때는 **CSS로 보완**이 필요할 수 있음.

```css
html, body {
  height: 100%;
  position: relative;
}

```

---

### 6. **Next.js 등 SSR 환경에서는 주의 필요**

- `document`나 `$`가 없기 때문에 클라이언트 사이드에서만 사용해야 함.

```jsx
useEffect(() => {
  if (typeof window !== 'undefined') {
    import('waitme').then(() => {
      // waitMe 사용 코드
    });
  }
}, []);
```

## 실제로 어디에 쓰고 있나

Django + jQuery 프로젝트에서 **AJAX 구간 로딩 표시**로 씁니다. 패턴은 항상 같습니다 — `beforeSend`에서 켜고 `complete`에서 끄기:

```js
function run_waitMe(el) {
  el.waitMe({ effect: 'ios', text: 'Please wait...', bg: 'rgba(255,255,255,0.7)', color: '#000' });
}

$.ajax({
  url: uri,
  beforeSend: () => run_waitMe($('table#classInfo')),   // 요청 직전 켜기
  success: (json) => { /* 렌더 */ },
  complete: () => $('table#classInfo').waitMe('hide'),  // 성공이든 실패든 끄기
});
```

포인트는 끄는 자리가 `success`가 아니라 **`complete`** 라는 것 — 요청이 실패해도 로딩은 꺼져야 합니다. `success`에만 두면 에러 시 스피너가 영원히 도는 화면이 되는데, 위의 3번(자동 종료 없음)과 결합해 실제로 겪기 쉬운 조합입니다.

**한계** — jQuery 의존 라이브러리라 이미 jQuery를 쓰는 레거시에서만 의미가 있습니다. React·Vue 프로젝트라면 CSS 스피너 컴포넌트가 맞고, 이 프로젝트에서도 jQuery를 걷어내는 날이 오면 같이 걷힐 목록에 있습니다. 웹팩 번들에 넣을 때의 CSS 순서 문제는 [웹팩 설정 변경 시 주의사항](/blog/webpack-변경-시-주의사항)에 있습니다.

# [ZBF] 6월 10일 코딩테스트 : 다양한 진법과 변환 알고리즘

> 이 글은 [네이버 블로그](https://blog.naver.com/ggamjige8888/223473623545)에 2024년 6월 10일에 올렸던 것을 그대로 옮겨온 것입니다.

진법은 숫자를 표현하는 방식으로, 기본적으로 사용하는 10진법 외에도 2진법, 8진법, 16진법 등이 있습니다. 각 진법은 특정한 숫자 집합과 자리값을 사용하여 수를 표현합니다.

1. 2진법 (Binary)

2진법은 0과 1 두 가지 숫자만 사용하는 진법으로, 컴퓨터 시스템에서 기본적으로 사용됩니다. 각 자리의 값은 2의 거듭제곱으로 계산됩니다.

이진수 변환 알고리즘 (10진수를 2진수로)

1. 입력된 10진수를 2로 나누고, 나머지를 기록합니다.

2. 몫을 다시 2로 나누고, 나머지를 기록합니다.

3. 몫이 0이 될 때까지 이 과정을 반복합니다.

4. 기록한 나머지를 역순으로 읽으면 이진수가 됩니다.

**1. 10진수를 2진수로 변환**

```js
function decimalToBinary(n) {
    let binary = '';
    while (n > 0) {
        binary = (n % 2) + binary;
        n = Math.floor(n / 2);
    }
    return binary || '0';
}

console.log(decimalToBinary(11)); // 출력: 1011
```

2. 8진법 (Octal)

8진법은 0부터 7까지의 숫자를 사용하는 진법으로, 각 자리의 값은 8의 거듭제곱으로 계산됩니다.

8진수 변환 알고리즘 (10진수를 8진수로)

1. 입력된 10진수를 8로 나누고, 나머지를 기록합니다.

2. 몫을 다시 8로 나누고, 나머지를 기록합니다.

3. 몫이 0이 될 때까지 이 과정을 반복합니다.

4. 기록한 나머지를 역순으로 읽으면 8진수가 됩니다.

**2. 10진수를 8진수로 변환**

```js
function decimalToOctal(n) {
    let octal = '';
    while (n > 0) {
        octal = (n % 8) + octal;
        n = Math.floor(n / 8);
    }
    return octal || '0';
}

console.log(decimalToOctal(15)); // 출력: 17
```

3. 16진법 (Hexadecimal)

16진법은 0부터 9까지와 A부터 F까지의 문자를 사용하는 진법으로, 각 자리의 값은 16의 거듭제곱으로 계산됩니다.

16진수 변환 알고리즘 (10진수를 16진수로)

1. 입력된 10진수를 16으로 나누고, 나머지를 기록합니다. (나머지가 10 이상이면 A-F로 변환)

2. 몫을 다시 16으로 나누고, 나머지를 기록합니다.

3. 몫이 0이 될 때까지 이 과정을 반복합니다.

4. 기록한 나머지를 역순으로 읽으면 16진수가 됩니다.

**3. 10진수를 16진수로 변환**

```js
function decimalToHexadecimal(n) {
    const hexChars = '0123456789ABCDEF';
    let hexadecimal = '';
    while (n > 0) {
        hexadecimal = hexChars[n % 16] + hexadecimal;
        n = Math.floor(n / 16);
    }
    return hexadecimal || '0';
}

console.log(decimalToHexadecimal(31)); // 출력: 1F
```

**진법 간 변환**

**진법 간의 변환은 일반적으로 다음과 같은 두 단계를 거칩니다:**

**1. 기준 진법에서 10진법으로 변환: 각 자리 값을 10진법으로 변환하여 더합니다.**

**2. 10진법에서 목표 진법으로 변환: 앞서 설명한 알고리즘을 사용하여 목표 진법으로 변환합니다.**

**4. 2진수를 10진수로 변환**

```js
function binaryToDecimal(binary) {
    let decimal = 0;
    for (let i = 0; i < binary.length; i++) {
        decimal = decimal * 2 + parseInt(binary[i], 10);
    }
    return decimal;
}

console.log(binaryToDecimal('1011')); // 출력: 11
```

**5. 8진수를 10진수로 변환**

```js
function octalToDecimal(octal) {
    let decimal = 0;
    for (let i = 0; i < octal.length; i++) {
        decimal = decimal * 8 + parseInt(octal[i], 10);
    }
    return decimal;
}

console.log(octalToDecimal('17')); // 출력: 15
```

**6. 16진수를 10진수로 변환**

```js
function hexadecimalToDecimal(hexadecimal) {
    let decimal = 0;
    const hexChars = '0123456789ABCDEF';
    for (let i = 0; i < hexadecimal.length; i++) {
        decimal = decimal * 16 + hexChars.indexOf(hexadecimal[i].toUpperCase());
    }
    return decimal;
}

console.log(hexadecimalToDecimal('1F')); // 출력: 31
```

**7. 2진수를 16진수로 변환**

```js
function binaryToHexadecimal(binary) {
    const decimal = binaryToDecimal(binary);
    return decimalToHexadecimal(decimal);
}

console.log(binaryToHexadecimal('1011')); // 출력: B
```
